# Demonstration datasets

`demo_claims.csv` consists of synthetic examples created for this project. The project contributors dedicate this demo input to the public domain under CC0-1.0, to the extent of their rights. The examples are **not** real insurance records.

`demo_catalog.csv` is a small independently curated demonstration list of publicly known vehicle make/model names. It is **not** the complete production vehicle catalog and is not a validated reference of all model variants or available powertrains. The script outputs are not ground-truth labels.

The original `vehicle_catalog.csv` used in the reported experiments is intentionally **not included**: external source licensing and redistribution permissions require separate confirmation.

The catalog schema is: `brand,model,vehicle_type,aliases,source`. Provide your own appropriately licensed catalog to use this tool on a larger dataset.
